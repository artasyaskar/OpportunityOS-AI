## 🌟 What is OpportunityOS?

Finding the right opportunity is overwhelming. Applying for it is exhausting. **OpportunityOS AI** completely flips the script. 

Instead of endless scrolling and generic applications, you simply build your **Opportunity DNA** (your skills, background, and evidence) inside our secure **Evidence Vault**. From there, your personal **AI Chief Officer** takes over. It autonomously scans global databases, calculates your exact match probability, and recommends the highest-leverage paths for your career.

When you find an opportunity you love, you enter the **Application War Room**, an AI-powered document workshop that helps you craft the perfect application based on the exact documents you've uploaded.

## ✨ Core Features

*   🧠 **AI Chief Officer:** Your autonomous agent that works in the background to map your profile against global databases, finding "hidden gem" opportunities you might have missed.
*   📊 **Evidence Vault:** A highly secure, centralized locker for your transcripts, resumes, portfolios, and identity documents. The AI uses this data to assess your readiness and generate tailored application materials.
*   🎯 **Probability Engine:** Before you waste hours applying, the system calculates an **Opportunity Score** out of 100, telling you exactly how likely you are to win an award or land a role based on your current profile.
*   ⚡ **Application War Room:** Step-by-step intelligence tracking, document drafting, and preparation tools dedicated to helping you beat the competition.
*   🤖 **Executive Advisor:** A real-time chat interface available across your dashboard to provide strategic advice, review essays, or just help you navigate the platform.

## 🚀 Getting Started

Want to run the platform locally? Follow these steps:

### 1. Clone the repository
```bash
git clone https://github.com/artasyaskar/OpportunityOS-AI.git
cd OpportunityOS-AI
```

### 2. Install dependencies
```bash
npm install
# or yarn install
```

### 3. Set up Environment Variables
Create a `.env.local` file in the root directory and add your Firebase and API keys. You'll need:
*   Firebase Client Configuration (API Key, Auth Domain, Project ID, etc.)
*   Firebase Admin SDK Credentials (for the backend API routes)
*   Your AI Provider API Keys

### 4. Run the development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser. You will be greeted by the landing page!
